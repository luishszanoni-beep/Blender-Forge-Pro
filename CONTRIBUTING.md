# Contributing

Contribuições são bem-vindas quando preservam as oito skills e as regras de auditoria do Blender Forge Pro.

1. Abra uma issue descrevendo o problema, sem postar informações sigilosas.
2. Faça sua alteração em uma branch separada e envie um pull request com escopo pequeno.
3. Rode `python scripts/security_scan.py`, `python -m compileall -q scripts tests` e os testes de subsistema aplicáveis.
4. Inclua evidências verificáveis quando afirmar que algo funciona no Blender ou Roblox Studio; testes de JSON não validam a aparência final.
5. Não acrescente dependências, extensões, fontes remotas ou downloads automáticos sem descrever os riscos e exigir consentimento quando necessário.

**Importante:** as imagens e o PDF privados ainda pendentes não devem ser substituídos por arquivos fictícios ou cópias sem proveniência.
