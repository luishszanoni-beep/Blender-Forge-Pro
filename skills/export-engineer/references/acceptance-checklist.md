# Export Engineer | Acceptance Checklist

- [ ] Real files exist and size/hash computed.
- [ ] `.blend` remains editable and safe backup preserved.
- [ ] GLB parsed and imported into fresh scene if available.
- [ ] Geometry-requiring surface details survive export.
- [ ] Coordinates, units, orientation, pivot verified.
- [ ] Materials, UVs and textures compatible with target.
- [ ] Rig/animation checks performed when required.
- [ ] Delivery manifest exact; no fabricated success claims.

When any required item is unchecked, record a blocker or explicit `PENDING`/`UNKNOWN`; do not invent a passing test.
