# Geometry Architect | Acceptance Checklist

- [ ] Scene units and model bounding-box dimensions checked.
- [ ] Primary structure visible in neutral orthographic renders.
- [ ] No missing obligatory large structural components.
- [ ] Object names and custom part IDs stable.
- [ ] Construction thickness/pivots/clearances plausible.
- [ ] Bevel and subdivision artifacts reviewed.
- [ ] Baseline checkpoint saved without overwriting source.
- [ ] Auditor has front/side/top and 3/4 renders where meaningful.
- [ ] G1.5 numeric blueprint validated, all required parts in ordered steps, no duplicate part geometry.
- [ ] G1.5 plates derived from one JSON and independent auditor reports source-art fit; no numerical PASS used as visual approval.

When any required item is unchecked, record a blocker or explicit `PENDING`/`UNKNOWN`; do not invent a passing test.
