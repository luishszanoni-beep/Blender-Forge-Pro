# Fidelity Auditor | Acceptance Checklist

- [ ] Actual model or its verified renders inspected.
- [ ] Reference/camera compatibility documented.
- [ ] All required views assessed or explicitly waived.
- [ ] Geometry-only features have independent mesh proof.
- [ ] Fatal blockers override numeric scores.
- [ ] Per-part corrective actions identify owner skill.
- [ ] QA state matches evidence reality.
- [ ] Unverified export or unobserved viewpoints left UNKNOWN.
- [ ] G1.5 original art, numeric blueprint, phase sheets and geometry checked as separate evidence types.
- [ ] No numeric validator or simulated preflight accepted as proof of faithful 3D model.

When any required item is unchecked, record a blocker or explicit `PENDING`/`UNKNOWN`; do not invent a passing test.
