# Reference Analyst | Acceptance Checklist

- [ ] Every image has reference ID and view/projection.
- [ ] Primary silhouette and all required parts inventoried.
- [ ] Each feature references observed source or is marked inferred/unknown.
- [ ] Dimensions include source, units, tolerances and calibration status.
- [ ] Occluded faces do not carry unearned fidelity claims.
- [ ] Approved/locked components separated from exploratory hypotheses.
- [ ] Camera alignment assumptions documented before any quantitative image comparison.
- [ ] Handoff includes critical closeups and missing data list.
- [ ] G1.5 handoff contains part IDs, proposed attachment/pivot dependencies, and measured-vs-relative dimension basis.

When any required item is unchecked, record a blocker or explicit `PENDING`/`UNKNOWN`; do not invent a passing test.
