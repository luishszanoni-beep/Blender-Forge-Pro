# Topology Engineer | Acceptance Checklist

- [ ] Triangle count from evaluated mesh reported.
- [ ] Budget traced to explicit project requirement or labeled assumption.
- [ ] Highpoly remains available and unmodified.
- [ ] Normal/manifold issues reviewed in context.
- [ ] UV/bakes match requested texture workflow.
- [ ] Required geometric features survive optimized export.
- [ ] Pivot, origin, transforms and material slots checked.
- [ ] LOD evidence if LODs are promised.

When any required item is unchecked, record a blocker or explicit `PENDING`/`UNKNOWN`; do not invent a passing test.
