# Blender Forge Pro V1.4.0 — Adaptive Intelligence Router (AIR)

- Preserved all eight existing specialist skills; added no ninth skill.
- Added task-level 5-tier model domain class registry with 4 effort levels and synthetic demonstration registry separate from empty production template.
- Added quality-first risk assessment, cost/latency estimates, optional independently reviewed performance ledger and bounded escalation rules.
- Added DAG planner for read-only parallelism and scene-exclusive writing with optional cooperative filesystem lease.
- Added fail-closed AIR-managed Blender bridge preflight (`FORGE_AIR_MANAGED=1`) with project path checks and required lease; legacy unmanaged usage remains backward compatible.
- Added 7-task chair example, 5 AIR protocol references, CLI, portable standard-library router and offline unit tests.
- Runtime caveat: **no provider API model inference, true subagent creation or model setting update** is implemented by this plugin package. An external authorized and verified host is required to execute plans.
- Test caveat: a passing router/registry/unit test is not proof of Blender modeling quality; all existing G0-G8 gates and real Blender benchmark requirements remain in force.
